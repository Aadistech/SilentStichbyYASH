# Silent Stitch Studio ✨

> Bespoke handmade crochet, everlasting floral gajras, lotus hair charms, and artisanal drops.

Live showroom website for **Silent Stitch Studio** ([@silentstitch_studio](https://instagram.com/silentstitch_studio)).

## 🌸 Features
- **Artisan Color Palette**: Velvet plum-noir canvas with radiant crochet rose pink, antique botanical gold, and warm ivory accents sampled directly from the official studio emblem.
- **Latest Drops Catalog**: Featuring authentic studio pieces including *Gajra Mohabbat Wala*, *Lotus Bloom Hairpiece*, *Nazar Evil Eye Charm*, and *Love Letter & Heart Charms*.
- **Interactive Product Modal**: Detailed product views, material notes, and direct integration for WhatsApp and Instagram DM ordering with pre-filled messages.
- **Bespoke Crochet Estimator**: 4-step interactive order estimator for custom creations, colorway selections, and instant quote generation.
- **Craftsmanship Showcase**: Interactive stitch density simulator, technique spotlights, and customer testimonials.
- **Responsive & Accessible**: Seamlessly optimized for mobile, tablet, and desktop screens with glassmorphic cards and fluid animations.

## 🚀 Getting Started
Simply clone the repository and open `index.html` in any browser:
```bash
git clone https://github.com/Aadistech/SilentStichbyYASH.git
cd SilentStichbyYASH
```
Open `index.html` directly or serve via any static web server / Live Server.
